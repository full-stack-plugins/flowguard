# ADR: initial synchronous Rust library

Rust edition 2024, declared MSRV 1.90 (not yet tested), actual compiler rustc 1.99.0 (b940084d7 2026-09-28), Cargo 1.99.0. Local GitGuard currently requires Unix APIs; portability is not claimed. Exact direct registry dependencies: serde 1.0.228, serde_json 1.0.145, sha2 0.10.9; Cargo.lock freezes transitive versions. No async runtime, database, CLI, network client, approval issuer or Git writer is included. The GitGuard dependency invokes its bounded Git reader and writes a private temporary object store; FlowGuard does not mutate the analyzed repository. Local sibling GuardEngine/SpecGuard/GitGuard adapters are version 0.1.0 and are development-only dependencies.

Authorized-root reads canonicalize paths and reject absolute paths, traversal, colon/URI schemes and backslashes. Files must remain inside the authorized root and be regular files, with a caller-selected byte limit no greater than 16 MiB; reads cap at limit+1 to detect growth. Diagnostics omit input paths. The caller MUST keep the source checkout immutable during discovery. Canonicalization is not a race-free filesystem sandbox against hostile concurrent symlink replacement. OS-level isolated frozen checkouts are a prerequisite for authoritative use.

Graphs are bounded at 1024 nodes, 8192 edges and depth 64, further reducible by the caller; iterative traversal guarantees finite termination. Task references and obligations are bounded at 8192, coverage entries at 1024, serialized frozen input at 1 MiB. Graph scheduling is deterministic lexicographic Kahn traversal (bounded O(V²+E)), intentionally independent of caller insertion order. No policy scripts or document instructions execute. Discovery only hashes complete bytes; unreadable/missing/rejected sources remain terminal gaps. General parser wall-clock cancellation and multi-process audit retention are not implemented.
